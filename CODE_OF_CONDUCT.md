 # Code of Conduct

This project is intended to be a welcoming, professional space for people interested in EtherCAT diagnostics and tooling.

We follow a simplified version of the [Contributor Covenant](https://www.contributor-covenant.org/) and expect all participants to:

- **Be respectful and professional.** Do not use racist, sexist, or otherwise offensive language. Personal attacks, harassment, and trolling are not acceptable.
- **Assume good intent.** Many contributors are volunteering their time; be patient with questions and feedback.
- **Be inclusive.** Help create an environment where people of different backgrounds and experience levels can participate.
- **Focus on the work.** Critique ideas, designs, and code—not people.

These expectations apply to all project spaces, including:

- GitHub issues and pull requests
- Discussions in code review
- Any other communication channels used for project work

## Reporting issues

If you experience or witness unacceptable behaviour:

- If you feel safe doing so, you may ask the person to stop.
- You can also contact the maintainer privately (see the email on the maintainer’s GitHub profile or the project’s PyPI page) with details of what happened.

Reports will be treated as confidentially as reasonably possible. The maintainer may take any action they deem appropriate, including warning the offender, temporarily or permanently banning them from project spaces, or escalating to platform moderation.
